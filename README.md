# Data Engineering Understanding Project requirements
**Objective**: Design and implement a modern, reliable, and scalable data warehouse using PostgreSQL and Visual Studio Code, providing a centralized and trusted data model that supports downstream users with efficient data analysis and reporting.

**Specifications**:  
- Data source - Import data from csv file that is made using custom webscraper  
- Data quality - Data is sourced from CSV files generated by a custom-built web scraper  
- Scope - The data warehouse will focus on maintaining the latest available dataset rather than preserving historical versions of records  
- Integration - Each row represents a unique and authoritative record of an individual apartment listing. No need to Integrate other sources  
- Documentation - Provide clear and comprehensive documentation to support business stakeholders, data analysts, and downstream analytics

## Analytics & Reporting (Data Analysis)
**Objective**: Develop SQL-based analytical queries to generate detailed and actionable insights from the data

- Analysis of the Impact of Floor Level on Apartment Prices
- Analyze and identify the districts with the most affordable apartment prices
- Analyze the Impact of Proximity to the Metro on Apartment Prices by Number of Rooms
- Top 10 Most Common Apartment Sizes and Number of Rooms in the Market
- Analysis of the Impact of Building Type on Apartment Prices
